Deliverable 2

Design and Implement the User Interface for the Web Application

Project: PulseWork — Responsive Agile Task & Team Workspace Management Platform

Rubric Compliance & Evaluation Summary

  • Is the user interface visually appealing and easy to navigate? YES — Built with CSS custom property tokens, curated HSL color palette, dark/light theme switcher, Google Font typography ('Plus Jakarta Sans'), glassmorphism, sticky sidebar, and intuitive header.
  • Does the interface layout adapt well to different screen sizes and orientations? YES — Mobile (<768px), Tablet (768px-1100px), and Desktop (>1100px) responsive layouts with CSS Grid, Flexbox, and mobile hamburger drawer.
  • Does the interface include the required components and features, such as forms and buttons? YES — Complete reactive form with real-time validation, interactive Kanban board with action buttons, status progression, modals, and directory filters.

1. Visual Aesthetics & Design System Tokens

The application implements an enterprise CSS token architecture supporting one-click Dark and Light theming:

CSS Token Dark Mode Value Semantic Purpose
--bg-app #090d16 Deep navy root application background
--bg-card #131c31 Card surfaces with glassmorphism backdrop filter
--color-primary #6366f1 Vibrant indigo for main actions and focus rings
--color-success #10b981 Emerald for completed tasks and online status
--color-warning #f59e0b Amber for pending review and busy status
--color-danger #ef4444 Rose red for critical priority blockers and delete actions

2. Multi-Device Responsive Layout Strategy

  • Desktop (1100px+): Permanent sticky navigation sidebar with route indicators and sprint counter; 4-column Kanban sprint lanes; side-by-side reactive form with live card preview.
  • Tablet (768px - 1100px): Collapsible drawer sidebar; 2x2 wrapping Kanban columns; multi-column responsive metrics grid.
  • Mobile (<768px): Fixed top bar with hamburger menu; slide-out drawer with backdrop blur overlay; stacked single-column Kanban lanes; fluid touch targets for all buttons and inputs.

3. UI Components & Feature Catalog

  • HeaderComponent: Live search with two-way binding, theme toggle, activity notification popover with click-outside listener, and user avatar.
  • SidebarComponent: Route links with active state highlight, dynamic task counters, sprint progress bar, and sample reset action.
  • DashboardComponent: 5 KPI summary cards, circular SVG sprint gauge, category progress bars, upcoming milestones, and activity stream.
  • TasksComponent: Dual view mode toggle (Kanban vs Table List), multi-field filter toolbar, interactive status advancement triggers.
  • CreateTaskComponent: Reactive Form with FormBuilder, Validators (required, minLength, min, max), real-time live preview card, and tag chip manager.
  • TeamComponent: Member cards with interactive availability toggles (Online, Busy, Away) and workload capacity bars.
  • AnalyticsComponent: Displays project financial budget, sprint velocity, and average effort using Angular pipes.
