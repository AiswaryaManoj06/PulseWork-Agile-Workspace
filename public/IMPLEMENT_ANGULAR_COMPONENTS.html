Deliverable 3

Implement Angular Components for the Web Application

Project: PulseWork — Responsive Agile Task & Team Workspace Management Platform

Rubric Compliance & Evaluation Summary

Are the components correctly implemented and functional? YES (Exceeds Expectations)

Organized using Angular 19 Standalone Components with explicit dependency imports, input/output property decorators, reactive state services using RxJS BehaviorSubject, and full functionality verified across all routes.

1. Standalone Component Architecture

Component Selector Key Functionalities
AppComponent app-root Master container coordinating sidebar drawer and routing to /tasks
HeaderComponent app-header Dark/Light theme toggle, search binding, notification popup with click-outside listener
SidebarComponent app-sidebar RouterLink navigation, active route highlights, dynamic sprint counter, sample data reset
DashboardComponent app-dashboard KPI summary cards, circular SVG gauge, workload category progress bars, activity stream
TasksComponent app-tasks Kanban 4-column sprint lanes, table list mode, category/priority filter, quick status advancement
CreateTaskComponent app-create-task Reactive Forms (FormBuilder, Validators), real-time live preview card, tag chip manager
TeamComponent app-team Team member cards, real-time availability toggles (Online, Busy, Away), capacity meters
AnalyticsComponent app-analytics Velocity analytics, budget breakdown using Currency, Percent, Decimal, and Date pipes
TaskModalComponent app-task-modal Backdrop modal dialog, interactive progress slider, workflow transition buttons
NotificationToastComponent app-notification-toast Reactive floating toast alerts triggered on creation, update, and deletion

2. Services & State Management

  • TaskService: Central singleton service exposing reactive Observables (tasks$, team$, logs$) via RxJS BehaviorSubject with automatic browser localStorage persistence.
  • ThemeService: Angular modern Signals-driven service managing light/dark theme switching synchronized with document.body class lists.
  • ToastService: Dispatches timed interactive notifications.
