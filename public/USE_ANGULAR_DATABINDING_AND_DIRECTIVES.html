Deliverable 4

Use Angular Data Binding and Directives to Manipulate the User Interface

Project: PulseWork — Responsive Agile Task & Team Workspace Management Platform

Rubric Compliance & Evaluation Summary

  • Are data bindings and directives used correctly to manipulate the UI? YES — Implements all 4 types of data binding (Interpolation, Property, Event, Two-way) plus custom directives.
  • Is the UI updated dynamically in response to user input or changes in data? YES — Live form preview updates as user types, filter changes recalculate lanes, status advances move cards with animations.
  • Are directives used to conditionally display or hide UI elements? YES — @if used for error alerts, modals, overlays, and empty states; @for iterates tasks, columns, and tag chips; @switch maps notification icons.

1. Data Binding Implementations

Binding Type Syntax Pattern Concrete Application in PulseWork
Interpolation {{ expression }} {{ metrics.totalTasks }}, {{ estimatedBudget | currency:'USD' }}, {{ task.dueDate | date:'mediumDate' }}
Property Binding [property]="value" [disabled]="taskForm.invalid", [style.width.%]="cat.percentage", [class.is-invalid]="isFieldInvalid('title')"
Event Binding (event)="handler()" (click)="onToggleTheme()", (ngSubmit)="onSubmit()", (input)="onSearchChange()"
Two-Way Binding [(ngModel)]="field" [(ngModel)]="searchQuery", [(ngModel)]="selectedCategory", [(ngModel)]="task.progressPercentage"

2. Directives Implementation

  • Structural Directives (@if, @for, @switch):
    • @if (isFieldInvalid('title')) conditionally shows dynamic validation error alerts.
    • @if (task) conditionally renders the interactive task modal dialog and backdrop.
    • @for (col of columns; track col.status) renders the 4 Kanban sprint lanes.
    • @for (tag of currentTags; track tag) renders interactive tag chips.
    • @switch (log.type) renders distinct icons for create, status-change, and delete events.
  • Attribute Directives ([ngClass], [ngStyle]):
    • [ngClass]="task.priority | priorityBadge" applies severity styling (.badge-critical, .badge-high).
    • [ngStyle]="{ width: task.progressPercentage + '%' }" sets dynamic progress widths.
  • Custom Directives:
    • [appHoverElevate]: Dynamically manipulates host DOM styles with @HostListener and Renderer2 to elevate cards on hover.
    • [appPulseStatus]: Dynamically injects pulsing beacon for critical items.
    • [appClickOutside]: Detects outside clicks to dismiss dropdowns and modals.

3. Custom and Built-in Pipes

  • Built-in: CurrencyPipe, PercentPipe, DecimalPipe, DatePipe, UpperCasePipe, SlicePipe.
  • Custom: TimeAgoPipe (transforms timestamps to "5m ago", "2h ago"), PriorityBadgePipe.
