Part 1: Project Title

1. Project Title & Overview

Title: PulseWork — Responsive Agile Task & Team Workspace Management Platform

Description: An enterprise-grade, responsive single-page web application built with Angular 19 showcasing standalone components, reactive forms, real-time RxJS data binding, custom directives, pipes, Kanban and list views, and dark/light theming.

Part 2: UI Design & Responsiveness

2. Design and Implement the User Interface

Rubric Verification:

  • Visually Appealing & Easy to Navigate? Yes. Engineered with CSS custom property tokens, glassmorphism, responsive sticky sidebar, mobile drawer, and Dark/Light theme toggle.
  • Adapts to Different Screen Sizes? Yes. Mobile (<768px), Tablet (768px–1100px), and Desktop (1100px+) responsive breakpoints with CSS Grid and Flexbox.
  • Includes Required Components & Forms? Yes. Full header, sidebar, dashboard, dual-mode Kanban board, reactive form wizard, team directory, and analytics table.

Part 4: Data Binding & Directives

4. Angular Data Binding and Directives

Data Binding Evidence:

  • Interpolation: {{ metrics.totalTasks }}, {{ task.dueDate | date:'mediumDate' }}, {{ estimatedBudget | currency:'USD' }}
  • Property Binding: [disabled]="taskForm.invalid", [style.width.%]="cat.percentage", [class.is-invalid]="isFieldInvalid('title')"
  • Event Binding: (click)="onToggleTheme()", (ngSubmit)="onSubmit()", (input)="onSearchChange()"
  • Two-Way Data Binding: [(ngModel)]="searchQuery", [(ngModel)]="selectedCategory", [(ngModel)]="task.progressPercentage"

Directives Evidence:

  • Structural Directives: @if (isFieldInvalid('title')), @if (viewMode === 'kanban'), @for (col of columns; track col.status), @switch (log.type)
  • Attribute Directives: [ngClass]="task.priority | priorityBadge", [ngStyle]="{ width: task.progressPercentage + '%' }"
  • Custom Directives:
    • appHoverElevate: Dynamic 3D elevation and glow shadow on mouse hover using @HostListener and Renderer2.
    • appPulseStatus: Dynamically injects pulsing beacon for critical blocker tasks.
    • appClickOutside: Dismisses dropdowns and modals on external click.
